摘要

本课程大作业围绕新闻自动摘要任务展开，选用 CNN/DailyMail 数据集，将新闻正文作为输入，将人工撰写的 highlights 作为生成目标。该任务不是机器翻译，而是同一语言内部的长文本压缩与信息重写问题，适合使用 Encoder-Decoder 序列生成框架进行建模。

实验实现了三类基于循环神经网络的摘要模型：LSTM Encoder-Decoder、BiLSTM Encoder-Decoder，以及作为主模型的 BiLSTM Encoder + Attention + LSTM Decoder。通过对比实验可以观察到，单纯使用最终隐状态的 Seq2Seq 模型难以处理长新闻文本，而 Attention 机制能够让 Decoder 在生成摘要时动态关注输入文章的不同位置，因此在 ROUGE 指标上取得更好的结果。

在 500 条测试样本上的实验结果表明，BiLSTM + Attention 的 ROUGE-1/ROUGE-2/ROUGE-L 为 6.86/0.59/5.96，高于 LSTM baseline 的 2.53/0.00/2.53 和 BiLSTM baseline 的 3.23/0.00/3.23。为了说明开源预训练摘要方法的效果，报告还加入 DistilBART-CNN-12-6 作为对比，其 ROUGE 达到 43.12/20.76/29.69，说明在真实新闻摘要任务中，大规模预训练 Transformer 仍明显优于从零训练的 RNN 模型。

关键词：文本摘要；CNN/DailyMail；LSTM；BiLSTM；Attention；Seq2Seq；ROUGE；DistilBART

第一章 选题背景与意义

1.1 选题背景

随着互联网新闻、社交媒体和知识库内容快速增长，用户每天面对的信息量远超人工阅读能力。新闻报道通常包含事件背景、采访细节、引用和延伸讨论，而用户往往希望快速获得核心事实。因此，自动文本摘要成为自然语言处理中的重要应用之一。

文本摘要的目标是将长文本压缩为短文本，同时尽量保留原文的关键信息。与文本分类、情感分析等判别任务不同，摘要任务要求模型生成一段自然语言文本，既要覆盖核心内容，又要保持语言连贯。这使得摘要任务更能体现序列建模、上下文表示和生成式建模的综合能力。

本课程主题涉及 RNN、LSTM 及相关序列模型。新闻摘要天然具有输入序列长、输出序列短、前后依赖明显的特点，因此适合作为 RNN 类模型的综合实践任务。通过该任务，可以比较单向 LSTM、双向 LSTM 和 Attention 机制在长文本生成中的不同作用。

1.2 研究意义

本实验的意义主要体现在三个方面。第一，从课程实践角度，完整实现了从数据准备、模型训练到自动评价的端到端流程。第二，从模型理解角度，通过多组实验观察到双向编码和 Attention 对长文本摘要的影响。第三，从工程对比角度，引入开源预训练模型 DistilBART 作为参考，使实验结果不仅停留在 RNN 内部比较，也能反映现代摘要系统的实际水平。

第二章 任务定义与数据集

2.1 任务定义

本实验任务为英文新闻文本摘要。给定一篇新闻正文 article，模型需要生成对应的摘要 highlights。输入和输出均为英文文本，因此该任务不是翻译任务，而是同一语言中的信息压缩与重写。

输入 CNN/DailyMail 新闻正文 article，通常较长，包含完整新闻叙述。
输出 人工摘要 highlights，长度较短，强调新闻核心事实。
目标 生成与参考摘要语义接近、表达连贯的短文本。

2.2 数据集说明

CNN/DailyMail 是自动摘要领域常用数据集，原始文本来自 CNN 和 DailyMail 新闻网页。每条样本主要包含新闻正文和摘要要点。本实验使用 HuggingFace 上的 abisee/cnn_dailymail 数据集，配置版本为 3.0.0。

字段 含义 在本实验中的作用
article 完整新闻正文 模型输入序列
highlights 人工撰写的新闻摘要 模型训练目标与评价参考

2.3 实验数据规模

完整 CNN/DailyMail 数据集规模较大，从零训练 RNN 模型耗时较长。考虑到课程作业的可复现性和训练成本，本实验使用固定子集完成训练、验证和测试。

数据划分 样本数 用途
Train 5000 训练 RNN 模型参数
Validation 500 选择验证集损失最低的 checkpoint
Test 500 计算最终 ROUGE 指标

2.4 数据预处理

实验使用 t5-small tokenizer 对输入正文和目标摘要进行分词。虽然主模型并不是 T5，但使用成熟 tokenizer 可以避免手写词表、低频词处理和特殊符号处理带来的额外误差。正文最大长度设置为 400 token，摘要最大长度设置为 100 token，超长文本截断，不足部分 padding。

截断长度会影响结果。RNN 模型只看到前 400 个 token，如果新闻关键信息出现在后文，模型无法利用这部分内容。这是 RNN 摘要效果偏低的重要原因之一。

第三章 方法设计

3.1 整体思路

本实验采用 Encoder-Decoder 框架。Encoder 读取新闻正文并生成上下文表示，Decoder 根据上下文表示逐步生成摘要。为了观察不同 RNN 结构的效果，实验设计了三组模型：基础 LSTM、BiLSTM 和 BiLSTM + Attention。

分词与截断
Encoder 编码
Decoder 生成
ROUGE 评价

3.2 LSTM Encoder-Decoder

LSTM Encoder-Decoder 是本实验的基础 baseline。Encoder 使用单向 LSTM 按顺序读取输入正文，将最终隐状态传给 Decoder。Decoder 再根据该隐状态逐词生成摘要。该方法结构简单，但存在明显瓶颈：整篇新闻需要被压缩到固定长度的最终隐状态中，长文本中的细节容易丢失。

3.3 BiLSTM Encoder-Decoder

BiLSTM 在 Encoder 端同时使用前向和后向 LSTM。前向 LSTM 捕获从文章开头到当前位置的信息，后向 LSTM 捕获从文章结尾反向到当前位置的信息。两者拼接后形成更完整的上下文表示。相比单向 LSTM，BiLSTM 对输入文本的表示能力更强，但如果没有 Attention，Decoder 仍主要依赖最终状态，因此长文本瓶颈仍然存在。

3.4 BiLSTM + Attention 主模型

主模型在 BiLSTM Encoder 的基础上加入 Attention 机制。Attention 的作用是让 Decoder 在生成每一个摘要词时，根据当前生成状态选择性关注原文中的不同位置。这样模型不再只依赖 Encoder 的最后状态，而是能够动态读取整篇文章的局部信息。

Encoder BiLSTM 读取 article，得到每个输入位置的上下文表示。
Attention 根据 Decoder 当前状态计算原文各位置权重，形成上下文向量。
Decoder LSTM 结合上下文向量和历史输出，逐词生成 highlights。
图 1 主模型结构示意

从直观上看，摘要生成时不同词对应原文中的不同信息。例如生成新闻人物时应关注人物名称，生成事件结论时应关注新闻主句，生成地点或机构时应关注相关实体。Attention 正是为这种动态对齐提供了机制。

3.5 训练策略

训练过程中使用 teacher forcing，即 Decoder 下一步输入有一定概率使用真实目标词，而不是上一时间步模型预测词。本实验 teacher forcing ratio 设置为 0.5。损失函数使用忽略 padding token 的交叉熵损失，优化器为 Adam，并采用 gradient clipping 抑制 RNN 训练中的梯度爆炸。

3.6 开源预训练方法对比

为了回应“如何将 ROUGE 提升到二三十以上”的实验目标，报告加入了开源预训练摘要模型 DistilBART-CNN-12-6。该模型不是本课程作业的 RNN 主模型，而是作为现代开源方法参考。它已经在 CNN/DailyMail 上进行微调，并在评估时使用 beam search，因此能够取得远高于从零训练 RNN 的 ROUGE。

第七章 结果分析

7.1 为什么 Attention 有提升

LSTM 和 BiLSTM baseline 都需要将输入新闻压缩到有限隐状态中。对于短句任务，这种方式可能足够；但 CNN/DailyMail 的 article 很长，摘要又需要覆盖人物、事件、地点和结论等多个信息点，单个最终状态难以完整保存所有细节。Attention 允许 Decoder 在每个生成步重新选择关注的原文位置，因此能更好地处理长文本输入。

7.2 为什么 loss 最低不一定 ROUGE 最高

本实验中 LSTM 的 validation loss 略低，但 ROUGE 明显低于 BiLSTM + Attention。原因是 validation loss 在 teacher forcing 条件下计算，模型每一步都能看到真实前文；而测试时模型需要依赖自己已经生成的内容，一旦前面生成错误，后续错误会累积。因此，摘要任务不能只用 loss 判断好坏，最终仍应结合 ROUGE 和生成样例评价。

7.3 RNN 主模型效果偏低的原因

  1. 训练数据只有 5000 条，而从零训练生成模型通常需要更多样本。
  2. 输入长度截断为 400 token，新闻后半部分信息可能被丢弃。
  3. 普通 Seq2Seq 缺少 pointer/copy mechanism，难以复制新闻中的人名、地名和机构名。
  4. RNN 解码使用 greedy decoding，没有 beam search 和重复惩罚。
  5. 模型缺少 coverage mechanism，因此容易出现重复生成和标点异常。

7.4 开源方法为什么能达到二三十以上

DistilBART 的优势不是单一超参数带来的，而是预训练、任务微调、Transformer 架构和 beam search 共同作用的结果。它在大规模语料上学习过语言建模能力，又针对 CNN/DailyMail 摘要任务进行过 fine-tuning，因此即使在同样的 500 条测试子集上，也能显著超过从零训练的 RNN。

第八章 总结与展望

8.1 总结

本课程大作业完成了 CNN/DailyMail 新闻摘要任务的完整实现与实验分析。实验表明，在 RNN 系列模型中，BiLSTM + Attention 的效果最好，说明双向编码和注意力机制能够提升长文本摘要质量。虽然主模型 ROUGE 绝对值不高，但其相对 baseline 的提升趋势清晰，符合模型设计预期。

同时，DistilBART 对比实验显示，开源预训练摘要模型能够在同一测试子集上达到 ROUGE-1 43.12、ROUGE-2 20.76、ROUGE-L 29.69。该结果说明，如果目标是实际应用效果，预训练 Transformer 是更合适的选择；如果目标是理解 RNN 序列生成机制，BiLSTM + Attention 仍然是有教学价值的主模型。

8.2 后续改进方向

  1. 扩大训练集规模，使用完整 CNN/DailyMail 训练集训练更久。
  2. 为 RNN Decoder 加入 beam search，提高推理阶段生成质量。
  3. 引入 pointer-generator 机制，提高实体和关键词复制能力。
  4. 引入 coverage mechanism，减少重复生成。
  5. 尝试微调 T5、BART 或 PEGASUS，与 RNN 模型做更系统对比。
